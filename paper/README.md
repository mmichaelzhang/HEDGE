# Paper files

The camera-ready publication bundle uses these stable paths:

- `HEDGE-DTI.pdf`: main paper with its proceedings appendix.
- `appendix.pdf`: standalone appendix extract for convenient reading.
- `complete_supplemental_details.pdf`: extended supplemental details and results.

The extended supplement is a separate reading aid; it does not change the
protocol labels or implementation lineages described in the paper and code.
